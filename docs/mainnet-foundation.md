# MYRIX Chain

## Mainnet foundation

This phase adds the main operational modules required for a stable blockchain foundation:
- staking
- consensus
- storage
- network peer registry
- governance primitives
- bridge and VM scaffolding
- SDK basics
- rollup scaffolding

## Key adoption goals
- support multi-node validator participation
- allow persistent storage for chain state
- expose a public API layer
- prepare for smart contract and bridge integration
