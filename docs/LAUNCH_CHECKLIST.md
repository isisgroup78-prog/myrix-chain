# MYRIX Chain Mainnet Launch Checklist

## Pre-launch

- [ ] infrastructure ready
- [ ] validator machines provisioned
- [ ] private keys generated and backed up
- [ ] bootnodes running
- [ ] genesis file finalized
- [ ] public explorer live
- [ ] monitoring stack ready
- [ ] DDoS and firewall protections active

## Launch day

- [ ] all validators synced to genesis
- [ ] block production started
- [ ] consensus quorum reached
- [ ] public API healthy
- [ ] explorer shows blocks and txs
- [ ] wallet integration tested
- [ ] announcement posted

## Post-launch

- [ ] validate uptime
- [ ] validate finality and peer count
- [ ] monitor transaction rate
- [ ] audit validator health
- [ ] prepare bridge and rollup activation
- [ ] publish runbook updates
