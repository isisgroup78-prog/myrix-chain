# MYRIX Chain Architecture Summary

## Consensus
- BFT PoS consensus
- quorum-based block finalization
- validator voting and leader election

## Execution
- transaction validation
- state transitions
- nonce management
- gas accounting

## Network
- validator nodes and full nodes
- peer discovery and block propagation
- mempool and transaction relay

## Storage
- RocksDB state persistence
- block history
- snapshotting for recovery

## Applications
- explorer
- wallet
- validator dashboard
- bridge and rollup layer

## Mainnet requirements
- secure key custody
- infrastructure redundancy
- monitoring and alerts
- public RPC access
- governance and operational runbook
